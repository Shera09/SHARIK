# Administrator Manual - Super Admin & Organization Management

## Super Admin Portal Access
Navigate to `/super-admin` to manage platform tenants, subscriptions, custom domains, and global API keys.

### 1. Tenant Provisioning
- Create new organizations at `/super-admin/tenants`.
- Assign subscription plans (Free, Starter, Pro, Enterprise).
- Manage organization active/suspended status.

### 2. Custom Domain Setup
- Manage custom domain mappings at `/super-admin/domains`.
- Verify DNS CNAME record and issue SSL certificates via automated verification.

### 3. API & Webhook Management
- Provision system-wide API keys at `/super-admin/api-platform`.
- Configure webhook subscriptions and inspect webhook event logs.
