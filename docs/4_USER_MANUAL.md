# CRM User Manual - Business Workflows

## Core Operations

### 1. Lead & Pipeline Management (`/leads`)
- Add new sales leads, update pipeline stages (`new` -> `contacted` -> `qualified` -> `proposal` -> `won`).
- Track deal values, probability, and follow-up schedules.

### 2. Invoicing & Online Payments (`/invoices`)
- Generate itemized GST-compliant invoices.
- Send payment links to customers to accept payments via Razorpay.

### 3. WhatsApp & Email Campaigns (`/whatsapp`, `/wa-campaigns`, `/email-campaigns`)
- Send direct chat messages via WhatsApp Cloud API.
- Schedule promotional email and WhatsApp broadcasts.
